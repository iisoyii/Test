# Tic Tac Toe — Vanishing Edition

A twist on classic Tic Tac Toe: each player can only have **3 pieces on the board** at a time. Place your 4th piece and your oldest one disappears!

## Features
- 2-player mode (same screen)
- vs Computer (minimax AI)
- Faded piece shows which one vanishes next
- Score tracker

## How to deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `tictactoe`)
2. Upload the contents of this folder (just `index.html` and this `README.md`)
3. Go to **Settings → Pages**
4. Under **Source**, select **Deploy from a branch**
5. Choose **main** branch and **/ (root)** folder, then click **Save**
6. Your game will be live at `https://<your-username>.github.io/<repo-name>/`
