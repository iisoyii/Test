# Tic Tac Toe — Vanishing Edition

A twist on classic Tic Tac Toe: each player can only have **3 pieces on the board** at a time. Place your 4th piece and your oldest one disappears!

## Features
- 2-player mode (same screen)
- vs Computer (minimax AI)
- Faded piece shows which one vanishes next
- Score tracker
